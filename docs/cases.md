## 如何运行案例

### 1. 克隆仓库

```bash
git clone https://github.com/321424890/vitepress-doc-main.git
cd vitepress-doc-main
```

### 2. 安装依赖

```bash
npm install
```

### 3. 启动开发服务器

```bash
npm run docs:dev
```

### 4. 构建生产版本

```bash
npm run docs:build
```

## 案例开发指南

### 技术栈

- **框架**：Vue 3
- **组件库**：crystalplus UI
- **构建工具**：Vite
- **样式预处理**：SCSS/Less

### 开发流程

1. **初始化项目**：使用 Vite 创建 Vue 3 项目
2. **安装依赖**：添加 crystalplus UI 及相关依赖
3. **配置按需导入**：优化打包体积
4. **开发组件**：使用 crystalplus UI 组件构建页面
5. **测试与构建**：确保项目质量
6. **部署上线**：发布到生产环境
